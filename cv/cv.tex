\section{Data Science \& Machine Learning Projects}

\project{Football Match Outcome Prediction \& Transfermarkt Data Audit}
  {\href{https://github.com/Shah-123/football-match-outcome-prediction}{GitHub} \textbar{} 2026}
  {Python, pandas, scikit-learn, Plotly}
\begin{itemize}
  \item Wrote a standard-library ETL that audits a 10-table Transfermarkt export and
        outputs an analysis-ready core of 31 leagues (2012--2025): 63K games, 1.6M appearances,
        2.3M lineup rows and 900K match events.
  \item Scoped the core by measured join coverage (100\% for domestic leagues vs.\ 28\% for cups) so
        joins cannot silently drop rows; fixed uncounted second-yellow dismissals and renamed
        scrape-date fields that would leak future data.
  \item Parsed own goals from free text, lifting scoreline reconciliation from 91.2\% to 98.5\%;
        showed that league-position columns were post-match standings (target leakage) and excluded them.
  \item Predicted Premier League outcomes with sequential Elo ratings and rolling 5-match form built
        without look-ahead. On a time-based holdout of 760 matches (2024--25): \textbf{48.0\% accuracy
        vs.\ 41.7\% majority baseline} and 45.4\% for club identity alone (macro-F1 0.36, log loss
        1.05); near-zero draw recall is documented, not hidden.
\end{itemize}

\project{Emotion Detection from Text: NLP Classifier \& API}
  {\href{https://github.com/Shah-123/Emotion_detection}{GitHub} \textbar{} 2026}
  {TensorFlow/Keras, scikit-learn, Hugging Face Datasets, FastAPI, Docker, pytest}
\begin{itemize}
  \item Built a 6-class emotion classifier on \textit{dair-ai/emotion} (16K train, 2K test). EDA of
        class imbalance (joy 33.5\% vs.\ surprise 3.6\%) and sentence length (95th percentile:
        41 words) set a 50-token input.
  \item SimpleRNN and LSTM baselines failed to converge; a BiLSTM with spatial dropout, global
        max-pooling, early stopping and learning-rate scheduling reached \textbf{92.5\% test accuracy,
        macro-F1 0.88}.
  \item Deployed a FastAPI endpoint and web UI in Docker; fixed a train/serve padding mismatch and
        normalised apostrophes and accents, recovering a 0.2-point accuracy drop on realistically
        typed input (8 unit tests).
\end{itemize}

  {\href{https://github.com/Shah-123/Ai-Content-Facotry}{GitHub} \textbar{} 2025--26}
  {BS Final Year Project, team of 2 \textbullet{} LangGraph, ChromaDB, OpenAI \& Gemini APIs,
   FastAPI, React, PostgreSQL, Docker}
\begin{itemize}
  \item Co-developed a 17-node LangGraph workflow turning one topic into a fact-checked article,
        social posts, podcast and video, with parallel writers, checkpointed crash recovery and
        human-in-the-loop review.
  \item Built RAG over uploaded documents: embedding-based semantic chunking and ChromaDB retrieval
        with fallbacks.
  \item Designed the evaluation stack: an in-graph G-Eval judge (coherence, relevance, accuracy, tone),

        states the limits (the same model writes and judges; n = 3).
  \item Built an ablation experiment with deterministic repetition and source-concentration metrics,
        so results do not depend on an LLM judge; shipped with CI and 200+ pytest tests.
\end{itemize}
