    01 // about

              [ about.md ]
            
    
            
    
              
    
                I work where LLM engineering meets applied machine learning — turning papers
                and prototypes into pipelines that hold up under evaluation.
              
    
              
    
                My focus is systems where correctness is auditable: supervisor-routed
                agent graphs, hybrid retrieval that fuses BM25 with dense vectors and reranks,
                citation audits against an authenticated corpus, and human-in-the-loop interrupts
                that stop a pipeline before it commits something wrong.
              
    
              
    
                I also build the unglamorous half properly — data pipelines, evaluation harnesses,
                feature engineering and deployable interfaces — because a model nobody can
                interrogate isn't finished.
              
    
              
    
                currently Final-year CS (AI Specialization) at the
                University of Peshawar · exploring LLM fine-tuning (LoRA / QLoRA), RAG evaluation
                and multi-modal agents.

                Final Year Project
              
    

              
    
                
    MootCourtSimulator
    
                
    Voice-first AI moot-court simulator
    
                
    
                  ★
                  Honorable Mention — Top 5 of 35 projects · GIK Institute, Aug 2026
                
    
                
    
                  A multi-agent courtroom in which a LangGraph supervisor routes between
                  independent Judge, Opposing Counsel and Witness agents over two-tier memory.
                  Retrieval fuses BM25 with dense vectors, reranks, and audits every citation
                  against an authenticated legal corpus — so an objection is grounded in statute,
                  not plausibility.

    • Architected a multi-agent courtroom simulator on a LangGraph state machine,
                    with a supervisor router orchestrating independent Judge, Opposing Counsel and
                    Witness agents backed by two-tier memory.
      • 
                  
    • Implemented ReAct-based Judge agents with dynamic statute-lookup tools,
                    and Opposing Counsel executing autonomous evidentiary objections verified against
                    the Qanun-e-Shahadat Order 1984.
      • 
                  
    • Engineered a hybrid RAG pipeline fusing BM25 and dense vector search via
                      RRF (k = 60), with LLM reranking and an automated citation-audit engine
                    against an authenticated legal corpus.
      • 
                  
    • Built a contract-first microservice streaming architecture
                    (Express API + Python FastAPI) supporting real-time STT/TTS, optimising
                    time-to-first-audio from 16.1s to 6.9s.
      • 
                  
    • Established a quantitative evaluation harness measuring retrieval
                    performance (MRR 1.00) and multi-agent courtroom behaviour across 32 labelled
                    scenarios — Objection F1 1.00, ground accuracy 100%.

                04
              
    

              
    
                
    ChessMastermind
    
                
    Custom chess AI engine — written from scratch
    
                
    
                  No LLM, no engine library doing the thinking. A search engine built from first
                  principles: minimax with alpha-beta pruning, iterative deepening, aspiration
                  windows and quiescence search, over a hand-written positional evaluation.
                
    

                
    
                  
    
                    
    Search

    • Developed a chess engine from scratch implementing minimax with alpha-beta
                      pruning, iterative deepening, aspiration windows and quiescence search.
      • 
                  
    • Engineered transposition tables (FEN hashing), MVV-LVA move ordering,
                      killer moves and history heuristics for search optimisation.
      • 
                  
    • Wrote evaluation functions analysing piece-square tables, pawn structure
                      (passed / isolated), king safety and knight outposts.
